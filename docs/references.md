# Linux systems engineering — primary references

These are public technical references relevant to the exercises in this repository.

## Userspace and POSIX

- [Linux man-pages project](https://man7.org/linux/man-pages/) — system calls, file descriptors, process management, threads and IPC
- [GNU GDB documentation](https://sourceware.org/gdb/documentation/) — source-level and postmortem debugging
- [strace documentation](https://strace.io/) — tracing userspace system calls

## Linux kernel

- [Kernel external module build documentation](https://docs.kernel.org/kbuild/modules.html) — Kbuild and out-of-tree modules
- [Kernel core APIs](https://docs.kernel.org/core-api/index.html) — memory management, synchronization and execution infrastructure
- [Kernel workqueues](https://docs.kernel.org/core-api/workqueue.html) — deferred execution
- [Kernel locking documentation](https://docs.kernel.org/locking/index.html) — mutexes, spinlocks and lock debugging
- [Linux I²C client drivers](https://docs.kernel.org/i2c/writing-clients.html) — driver registration and matching
- [Industrial I/O (IIO)](https://docs.kernel.org/driver-api/iio/index.html) — sensor/measurement device framework

## Embedded Linux and build systems

- [Yocto Project documentation](https://docs.yoctoproject.org/) — recipes, BSP layers, images and toolchains
- [U-Boot documentation](https://docs.u-boot.org/) — platform bootloaders

The links are study references, not evidence that every topic is implemented in this repository. See each module's README for actual source and tests.
