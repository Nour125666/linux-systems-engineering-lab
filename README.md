# Linux Systems Engineering Lab

A long-term, hands-on engineering portfolio focused on Linux systems programming, kernel development, device drivers, and embedded Linux.

## Objectives

- Develop strong C programming and Linux internals knowledge.
- Understand Linux system calls, memory management, processes, concurrency, and networking.
- Learn Linux kernel compilation, debugging, and device driver development.
- Build reproducible embedded Linux systems using Yocto and QEMU.
- Practice testing, debugging, technical documentation, and open-source development.

## Development environment

- Ubuntu on WSL2
- x86_64 Linux
- GCC, GDB, Git, strace, GNU Binutils
- QEMU for isolated kernel development

## Repository organization

- `docs/` — Learning log and technical references
- `month-XX/week-XX/` — Weekly exercises, code, tests, and debugging reports

## Engineering approach

Every exercise will aim to include:

1. A description of the problem.
2. An implementation with documented assumptions.
3. Reproducible build and execution instructions.
4. Functional tests and important failure cases.
5. A written explanation of the results.
